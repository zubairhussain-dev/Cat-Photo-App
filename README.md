# Cat Photo App

![Project Preview](preview.jpg)

This repository contains the solution for the **"Build a Cat Photo App"** workshop from the freeCodeCamp Responsive Web Design certification. The project focuses on building a simple HTML5 web page using semantic elements and standard best practices.

## Project Objective
The goal of this workshop is to build a web page that displays cat photos, lists, and captions using basic HTML elements.

## User Stories & Features
Based on the submitted code, this project implements the following features:

* **Structure:**
    * Uses the standard HTML5 boilerplate including `<!DOCTYPE html>`, `html`, `head`, and `body` tags.
    * Organizes content using semantic tags like `<main>`, `<section>`, and `<footer>` to improve SEO and readability.
* **Typography:**
    * Uses standard headings (`h1`, `h2`, `h3`) to create a clear hierarchy.
    * Includes paragraphs (`p`) and emphasis (`em`, `strong`) for text styling.
* **Media & Links:**
    * Displays images using the `img` tag with accessible `alt` attributes.
    * Uses `figure` and `figcaption` to semantically associate images with captions.
    * Includes anchor tags (`a`) linking to external pages, using `target="_blank"` to open in new tabs.
* **Lists:**
    * Displays an **Unordered List** (`ul`) for "Things cats love".
    * Displays an **Ordered List** (`ol`) for "Top 3 things cats hate".
